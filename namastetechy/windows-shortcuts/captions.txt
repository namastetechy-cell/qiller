Agar Windows ye 5 shortcuts nahi jaante, to roz time waste kar rahe ho.
Aur number 1 to sabse zyada useful hai.
Number 5: jab bhi seat chhodo, to Windows + L dabao aur laptop ko turant lock karo.
Number 4: Windows + dot dabane se PC par emoji keyboard open hota hai.
Number 3: browser mein galti se tab band ho gaye, to bhai Ctrl + Shift + T aur sab wapas.
Number 2: Windows + V, clipboard history. Jo bhi copy kiya, sab yahan.
Pehli baar ek click se on karo.
Aur number 1: Windows + Shift + S. Screen ka koi bhi hissa, ab tum screenshot le sakte ho.
